# PeopleSearch

An Equicord / Vencord user plugin that finds people in a server, or across all your servers, by words in their bio, pronouns or names. You can filter by friend status. It remembers the people you come across, so you can find them later, even by what their avatar looks like.

It also adds a **Profile** button to Discord's message search, next to **Filters**. The button opens the profile of the user the search is filtered on with `from:` or `mentions:`.

**Archived.** This plugin is no longer developed. Its successor is the SeenBook plugin, a frontend for a self-hosted seenbook server.

## Install

Clone into `src/userplugins/peopleSearch` of your Equicord or Vencord checkout, then build.
